# Streamcut

Streamcut находит эфиры GTA VI, готовит вертикальные клипы и планирует Shorts на одном RU-канале YouTube. Поиск работает отдельно для русского, английского и испанского языков.

В режиме MVP сервис берёт десять активных каналов категории Grand Theft Auto VI по числу текущих зрителей и проверяет их записи. Подтверждённый исходник поступает через входящую папку или официальный Twitch API скачивания клипов, если подключён токен автора или редактора.

## Что работает

- **Очередь** держит до десяти готовых клипов на язык. Для RU готовый MP4 заранее отправляется в календарь YouTube при свободном слоте. После подтверждения даты YouTube освобождается место для нового монтажа. При заполненном расписании клипы остаются локально.
- **Источники** принимают ссылки, локальные видео через браузер и материалы из входящих папок. Автопоиск обновляет до десяти авторов на направление каждые пять часов. Нужны [ключи API](control-room/CREATORS.md). Файл с именем по ID источника автоматически связывается с найденной записью.
- **Монтаж** из панели и CLI использует один редактор на Python и FFmpeg. Веб-камера идёт сверху, геймплей снизу, между ними короткий заголовок. Субтитры берутся из SRT или распознаются по исходному звуку. Можно задать точные интервалы, выбрать моменты по сигналу записи или поручить выбор локальной модели Ollama.
- **Аккаунты** поддерживают OAuth YouTube и предварительную загрузку Shorts с `publishAt`. Планирование включается владельцем после подключения RU-канала. Даты, подтверждённые YouTube, можно переносить из панели.
- **Подключения** проверяют выход к API. Неисправный выбранный маршрут ставит его задания на паузу. После восстановления безопасные задания получают новый слот. Неизвестный исход уже начатой отправки требует сверки с площадкой.

Рабочая панель использует SQLite. Сайт с примерами показывает интерфейс отдельно от рабочего сервиса. В этом публичном репозитории только исходный код, документация, лицензированный шрифт и синтетические примеры.

## Запуск из клона

Требуются Python 3.11+, FFmpeg и ffprobe. Node.js нужен для проверок интерфейса, сборка фронтенда не требуется.

```sh
git clone https://github.com/nuclear4ik/gta-stream-clips.git
cd gta-stream-clips/control-room
python3 studio.py --data .streamcut-data
```

Откройте рабочую панель, выберите «Источники → Добавить источник» и загрузите доступный вам исходник. В разделе «Монтаж реакции» задайте области кадра и добавьте SRT. Готовые MP4 можно смотреть и скачивать из карточки источника без подключения аккаунтов. [Рабочая панель](http://127.0.0.1:8765/)

В режиме «Точные интервалы» каждая строка содержит начало и конец фрагмента. Для режима «Нейросеть по SRT» запустите локальную Ollama и передайте сервису `STREAMCUT_OLLAMA_MODEL` с именем установленной модели. Встроенный отбор по записи и ручные интервалы работают без Ollama. [Инструкция по монтажу в панели](control-room/README.md#монтаж-реакции)

```sh
# Из корня репозитория
python3 -m unittest discover -q
cd control-room
python3 -m unittest discover -q
npm test
npm run check
# Если kubectl установлен
kubectl kustomize deploy
```

## Структура

- Панель и воркер работают в одном процессе `control-room/studio.py`. Воркер связывает источники, SQLite и готовые файлы, запускает редактор.
- `clips.py`, `editing.py` и `captions.py` отвечают за нарезку, компоновку и субтитры. [Инструкция редактора](docs/EDITOR.md)
- `control-room/regional.py` отвечает за региональный поиск, `control-room/moment_model.py` — за выбор моментов по SRT. [Устройство панели](control-room/README.md)
- [Аккаунты и маршруты](ACCOUNT_SETUP.md) — регистрация своих аккаунтов, OAuth, проверка сети и пилот.
- [Развёртывание](control-room/deploy/README.md) — Docker и Kubernetes с закрытым доступом.
- [Требования](SYSTEM_REQUIREMENTS.md) — целевое устройство сервиса. Состояние реализации указано в начале документа.
