# Streamcut

Streamcut находит эфиры и архивы GTA VI, монтирует вертикальные клипы и предзагружает их в расписание RU-канала YouTube. Рабочая панель и фоновые задания используют одну локальную SQLite.

В локальном RU-режиме Twitch проверяется каждые 30 минут. Настроенные авторы имеют приоритет, а поиск также охватывает русскоязычные эфиры и свежие записи категории GTA VI. Запись появляется в рабочих источниках после получения файла. Исходник поступает по прямой ссылке от автора, из входящей папки или через Twitch API скачивания клипов с доступом автора или редактора. [Настройка источников](control-room/CREATORS.md)

## Что работает

- **Очередь** держит до 30 готовых RU-клипов. Подтверждение даты YouTube или отмена локальной отправки освобождает место для следующего монтажа. Планировщик использует получасовые слоты с 15:00 до 20:00 по Москве. Если суточный лимит допускает дополнительные ролики, сервис делит свободные интервалы внутри этого окна.
- **Источники** продолжают обновляться при полной очереди и во время монтажа. Строгий RU-режим показывает только полученные материалы в обработке и время проверки Twitch. Когда кандидат не выдаёт файл, сервис переходит к следующему. [Ключи и разрешения Twitch](control-room/CREATORS.md)
- **Монтаж** из панели и CLI использует один редактор на Python и FFmpeg. Веб-камера идёт сверху, геймплей снизу, между ними короткий заголовок. Субтитры берутся из SRT или распознаются по исходному звуку. Можно задать точные интервалы, выбрать моменты по сигналу записи или поручить выбор локальной модели Ollama.
- **Аккаунты** поддерживают OAuth YouTube и предварительную загрузку Shorts с `publishAt`. Включите автопланирование один раз в карточке каждого RU-канала. При заполнении расписания первого канала следующий может принять ещё не отправленный ролик. Даты, подтверждённые YouTube, можно переносить из панели.
- **Подключения** проверяют выход к API. Неисправный выбранный маршрут ставит его задания на паузу. После восстановления безопасные задания получают новый слот. Неизвестный исход уже начатой отправки требует сверки с площадкой.

Статический предпросмотр панели использует синтетический ролик. Рабочая папка данных содержит `studio.db`, `inbox/`, `exports/` и локальную конфигурацию. Используйте тот же путь `--data` при обновлении или перезапуске.

## Запуск из клона

Требуются Python 3.11+, FFmpeg и ffprobe. Node.js нужен для проверок интерфейса, сборка фронтенда не требуется.

```sh
git clone https://github.com/nuclear4ik/gta-stream-clips.git
cd gta-stream-clips/control-room
python3 studio.py --data .streamcut-data
```

Откройте рабочую панель, выберите «Источники → Добавить источник» и загрузите доступный вам исходник. В разделе «Монтаж реакции» задайте области кадра и добавьте SRT. Готовые MP4 можно смотреть и скачивать из карточки источника без подключения аккаунтов. [Рабочая панель](http://127.0.0.1:8765/)

В режиме «Точные интервалы» каждая строка содержит начало и конец фрагмента. Для режима «Нейросеть по SRT» запустите локальную Ollama и передайте сервису `STREAMCUT_OLLAMA_MODEL` с именем установленной модели. Встроенный отбор по записи и ручные интервалы работают без Ollama. [Инструкция по монтажу в панели](control-room/README.md#монтаж-реакции)

```sh
# Из корня репозитория
python3 -m unittest discover -q
cd control-room
python3 -m unittest discover -q
npm test
npm run check
# Если kubectl установлен
kubectl kustomize deploy
```

## Рабочий цикл

- `control-room/studio.py` обслуживает панель из `control-room/dist/` и связывает фоновые задания с SQLite.
- `control-room/twitch_directory.py` читает каталог и архивы Twitch. `control-room/twitch_media.py` получает доступные файлы. `control-room/regional.py` поддерживает отдельный региональный режим поиска.
- `control-room/autocut.py` определяет область камеры и распознаёт речь. `control-room/moment_model.py` выбирает законченные интервалы. `clips.py`, `editing.py` и `captions.py` собирают MP4, сохраняют исходный звук и создают субтитры. [Инструкция редактора](docs/EDITOR.md)
- `control-room/schedule.py` подбирает время, `control-room/youtube_release.py` передаёт и сверяет расписание. `control-room/transport.py`, `connections.py` и `metrics.py` обслуживают маршруты, OAuth и доступную статистику. [Устройство панели](control-room/README.md)
- [Аккаунты и маршруты](ACCOUNT_SETUP.md) — регистрация своих аккаунтов, OAuth, проверка сети и пилот.
- [Развёртывание](control-room/deploy/README.md) — Docker и Kubernetes с закрытым доступом.
- [Фоновый запуск на Mac](docs/MACOS_LAUNCH.md) — сохранение существующей базы, автоматический перезапуск панели и воркеров.
- [Требования](SYSTEM_REQUIREMENTS.md) — целевое устройство сервиса. Состояние реализации указано в начале документа.
