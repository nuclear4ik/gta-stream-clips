# Montserrat ExtraBold

Source: https://github.com/google/fonts/tree/main/ofl/montserrat

Downloaded `Montserrat[wght].ttf` and `OFL.txt` from the official Google Fonts repository.
Created a static weight-800 instance using FontTools `instantiateVariableFont` with
`updateFontNames=True`. Family exposed to libass: `Montserrat ExtraBold`.

The full SIL Open Font License and copyright notice are in `OFL.txt`.
Runtime rendering does not require FontTools or a system font installation.
