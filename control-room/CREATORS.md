# Стартовые списки авторов

Поиск идёт по трём целевым аудиториям. Это редактируемая подборка известных авторов, а не рейтинг по текущим подписчикам. Включение в список не означает, что автор уже делал контент о GTA 6.

- **RU · Россия.** [Бустер](https://www.twitch.tv/buster/videos), [Bratishkinoff](https://www.twitch.tv/bratishkinoff/videos), [Recrent](https://www.twitch.tv/recrent/videos).
- **EN · США.** [Kai Cenat](https://www.twitch.tv/kaicenat), [CaseOh](https://www.twitch.tv/caseoh_), [LIRIK](https://www.twitch.tv/lirik).
- **ESP · Испания.** [Ibai](https://www.twitch.tv/ibai), [AuronPlay](https://www.twitch.tv/auronplay), [IlloJuan](https://www.twitch.tv/illojuan/videos).

## Как ищет

**YouTube.** На группу автора отправляется один запрос с вариантами `GTA 6`, `GTA VI`, `GTA6` и `Grand Theft Auto VI`. Для RU добавляются `ГТА 6` и `ГТА VI`. Поиск проверяет до 25 результатов первой страницы за последние три дня и пропускает анонсы предстоящих эфиров. Повторы с тем же ID видео учитываются один раз. [YouTube Data API](https://developers.google.com/youtube/v3/docs/search/list)

В каждом результате тема должна быть в заголовке видео, а имя автора — в заголовке или названии канала загрузчика. Поэтому принимается «Auron.Play смотрит GTA VI» у канала с другим названием, если в списке есть алиас `Auron Play`. Поиск сопоставляет имена без учёта регистра, нормализует Unicode и допускает разные разделители внутри составных имён. Границы имени отсеивают варианты вроде `AuronPlaycito`. Описание видео и явно отделённые рекламные или теговые блоки заголовка пропускаются. Например, «GTA V | #GTA6» и «GTA 6 | Sígueme: AuronPlay» у стороннего канала не проходят.

`regionCode` передаётся как `RU`, `US` или `ES` и учитывает доступность видео в регионе. `relevanceLanguage` указывает релевантный язык. Эти поля не доказывают страну автора или язык его речи, который проверяется перед автоотправкой. [Параметры поиска YouTube](https://developers.google.com/youtube/v3/docs/search/list#parameters)

**Twitch.** По точным логинам или числовым ID проверяются активные трансляции и до пяти публичных архивов каждого автора за последние три дня. Язык в метаданных должен совпадать с направлением (`ru`, `en` или `es`). Эфир подходит в категории GTA 6. Если категория пуста или указано `Just Chatting`, тема берётся из заголовка. В записи ищется тема в заголовке. Если эфир прошёл только по категории, сохранённое на время работы сервиса совпадение позволяет принять архив с тем же автором, языком, заголовком и `stream_id`. После перезапуска такой архив снова проверяется по заголовку. [Каналы](https://dev.twitch.tv/docs/api/reference/users#get-users), [эфиры](https://dev.twitch.tv/docs/api/reference/streams#get-streams), [записи](https://dev.twitch.tv/docs/api/reference/videos#get-videos)

ID эфира и `stream_id` его архива задают общий ключ. Ссылка ожидающего источника обновляется на VOD, и повторный поиск сохраняет одну запись. Архив без `stream_id` учитывается по собственному ID.

Обе платформы отдают ссылки и метаданные. Для монтажа нужен отдельный исходный файл, который вы вправе использовать.

## Настройка

При заданных ключах используются стартовые списки. Чтобы заменить список, задайте переменную для соответствующей площадки и языка. Пустое значение отключает поиск этой площадки по данному языку.

- `STREAMCUT_YOUTUBE_KEY` включает запросы YouTube Data API. `STREAMCUT_YOUTUBE_RU`, `STREAMCUT_YOUTUBE_EN`, `STREAMCUT_YOUTUBE_ESP` принимают до пяти групп авторов. Разделяйте группы символом `|`, а до четырёх вариантов имени внутри группы — запятыми. Каждый вариант может содержать до 70 символов. Первый вариант отображается в панели. Например, для RU можно задать `Бустер,Buster|Bratishkinoff,Братишкин|Recrent,Рекрент`.
- `TWITCH_CLIENT_ID` и `TWITCH_CLIENT_SECRET` включают Twitch Helix. `STREAMCUT_TWITCH_RU`, `STREAMCUT_TWITCH_EN`, `STREAMCUT_TWITCH_ESP` принимают до пяти логинов или числовых ID через `|`. Логины можно указать с `@`. Например, для RU можно задать `buster|bratishkinoff|recrent`.

Ключи API задаются в окружении сервера. Они не нужны для ручного добавления ссылки или файла.
