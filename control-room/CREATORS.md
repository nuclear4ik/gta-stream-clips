# Автопоиск авторов

Каждые пять часов Streamcut проверяет недавние видео и текущие эфиры о GTA 6 в YouTube и Twitch. Пауза или перезапуск сервиса сохраняет предыдущие результаты, а случайный повторный запуск не тратит квоту на новый поиск. Если API временно недоступен, доступные свежие результаты этой площадки остаются в списке.

## Как меняется список

- В каждом направлении отображается до десяти авторов с подтверждённым сигналом. Для записей учитывается скорость набора просмотров за последние три дня, для эфира — число одновременных зрителей в момент проверки. Позиции рассчитываются отдельно по площадке и типу материала. Позиции автора в разных группах складываются. Если подтверждённых авторов меньше десяти, список будет короче.
- YouTube ищет по теме и по группам псевдонимов. Перезалив попадает в кандидаты, если в основном заголовке или названии канала однозначно найден известный автор. Язык незнакомого автора ожидается в метаданных видео. `regionCode` задаёт доступность видео для рынка. Это не статистика страны зрителей или гражданство авторов. [YouTube Search](https://developers.google.com/youtube/data/reference/rest/v3/search/list), [YouTube Videos](https://developers.google.com/youtube/data/reference/rest/v3/videos/list).
- Twitch ищет в категории GTA 6 по языку и проверяет эфиры и записи стартовых авторов. Эфир и архив связываются по `stream_id`, в том числе после перезапуска. Активные эфиры отображают состояние на момент последнего запроса. [Twitch Streams](https://dev.twitch.tv/docs/api/reference/streams), [Twitch Videos](https://dev.twitch.tv/docs/api/reference/videos).
- Поиск YouTube делает до пяти запросов `search.list` на регион за цикл, до 75 за 24 часа при пяти циклах. Дополнительные сведения о видео берутся пакетно. Общее потребление Google Cloud зависит от остальных клиентов проекта. [Документация квот](https://developers.google.com/youtube/data/determine_quota_cost).

Пустое значение отключает стартовые имена для площадки и языка. Поиск за пределами списка продолжает идти, если настроены API.

## Как передать разрешённую запись на монтаж

Поиск сохраняет метаданные и ссылку. Для автоматически связанного монтажа кладите доступные для использования файлы в `inbox/RU`, `inbox/EN` или `inbox/ESP` с именами:

- `youtube-<video_id>.mp4` для видео YouTube;
- `twitch-vod-<video_id>.mp4` для записи Twitch;
- `twitch-stream-<stream_id>.mp4` для собственной записи эфира или записи, предоставленной с разрешением.

Передавайте файл с временным расширением и переименуйте после завершения копирования. Сервис может получить файл раньше метаданных и дождётся совпадения ID и языка. Альтернатива — кнопка «Добавить файл» у источника. Ни поиск, ни файл с произвольным именем не предоставляют права на чужой контент. Для публикации действует отдельная проверка языка, режима отправки, OAuth, канала и маршрута.
