# Поиск каналов Twitch

По умолчанию Streamcut повторяет три отдельных фильтра каталога Grand Theft Auto VI и сортирует активные эфиры по текущему количеству зрителей. Для каждого языка берутся первые десять уникальных каналов. Затем сервис проверяет до пяти свежих публичных архивов на канал. Если выбранный стример вышел из топа, сервис до суток отслеживает архив конкретного эфира по `stream_id`. Найденная запись остаётся доступна для получения до истечения окна в три дня. Каталог проверяется каждые 30 минут. [Twitch Get Streams](https://dev.twitch.tv/docs/api/reference/streams#get-streams) · [Twitch Get Videos](https://dev.twitch.tv/docs/api/reference/videos#get-videos)

Для поиска задайте `TWITCH_CLIENT_ID` и `TWITCH_CLIENT_SECRET`. Чтобы автоматически обработать предоставленную запись, сохраните её в `inbox/RU` как `twitch-vod-<id>.mp4`, где ID берётся из ссылки Twitch на архив. Копируйте под временным расширением и переименовывайте после завершения. В MVP автомонтаж по умолчанию применяется к RU.

В режиме каталога явный `STREAMCUT_TWITCH_RU` добавляет наблюдение за конкретными RU-каналами, даже если они уже завершили эфир. Укажите до 12 логинов или числовых ID через `|`. В интерфейсе текущий топ формируется отдельно по эфиру, а свежие архивы этих авторов попадают в источники. Поиск принимает архивы с темой GTA VI или архивы уже зафиксированных эфиров этой категории.

`STREAMCUT_TWITCH_STRICT_RU=1` включает поиск русскоязычных эфиров, архивов и клипов Grand Theft Auto VI. Каналы из `STREAMCUT_TWITCH_RU` сохраняют приоритет. Сервис обновляет первую страницу эфиров и продолжает обход глубоких страниц с сохранённой позиции. Он чередует подборки архивов и проверяет клипы длиной 25–60 секунд за свежие и более ранние интервалы. Клипы ищутся и во время эфира, когда у них ещё может отсутствовать ID архива. Рабочая очередь показывает материал после получения файла. При отказе сервис пробует следующего кандидата. [Twitch Get Streams](https://dev.twitch.tv/docs/api/reference/streams#get-streams) · [Twitch Get Videos](https://dev.twitch.tv/docs/api/reference/videos#get-videos) · [Twitch Get Clips](https://dev.twitch.tv/docs/api/reference/clips#get-clips)

Helix возвращает данные об архиве и ссылку на страницу. Готовый MP4 полной записи может предоставить автор, например из Video Producer или собственной записи. Задайте `STREAMCUT_TWITCH_ARCHIVE_INDEX` с абсолютным путём к локальному JSON, который обновляет доверенный поставщик файлов. Ключ — ID записи Twitch, `broadcaster_id` — числовой ID автора в виде строки, `url` — прямая HTTPS-ссылка на MP4. [Twitch Get Videos](https://dev.twitch.tv/docs/api/reference/videos#get-videos) · [Video Producer](https://help.twitch.tv/s/article/video-on-demand?language=en_US)

```json
{
  "123456789": {
    "broadcaster_id": "12345",
    "url": "https://media.example.com/gta/session.mp4"
  }
}
```

Сервис перечитывает индекс без перезапуска, сопоставляет ID записи и автора с Twitch и сохраняет MP4 в нужную входящую папку. Обновляйте индекс атомарной заменой файла. Подписанные ссылки храните только в приватном индексе. Используйте прямые адреса, возвращающие HTTP 200. Когда есть место в запасе, программа автоматически забирает следующий доступный архив и передаёт его в монтаж.

Публичный каталог клипов Twitch отдаёт метаданные и ссылку на просмотр. Для получения MP4 через Get Clips Download Twitch проверяет права владельца или редактора. Сервис использует уже выданное разрешение и пропускает результаты без доступного способа получения файла. [Twitch Get Clips Download](https://dev.twitch.tv/docs/api/reference/clips#get-clips-download)

1. Владелец канала разрешает существующему приложению `channel:manage:clips` через Twitch OAuth. Назначенный владельцем редактор может выдать разрешение `editor:manage:clips` от своей учётной записи. Используйте клиент приложения из `TWITCH_CLIENT_ID` и завершите Authorization Code Grant с зарегистрированным адресом возврата. [Twitch OAuth](https://dev.twitch.tv/docs/authentication/getting-tokens-oauth/#authorization-code-grant-flow)
2. В локальной конфигурации задайте `TWITCH_CLIENT_ID`, `TWITCH_CLIENT_SECRET` и `STREAMCUT_TWITCH_CLIP_EDITOR_ID_<broadcaster_id>`. Суффикс — числовой ID канала. Значение — числовой ID пользователя, который дал разрешение приложению. Если его дал сам владелец, оба ID совпадают.
3. Перезапустите локальную службу. Она получает токен приложения перед скачиванием и передаёт Twitch ID владельца и пользователя с разрешением. Права проверяет Twitch на каждом запросе. [Twitch Client Credentials](https://dev.twitch.tv/docs/authentication/getting-tokens-oauth/#client-credentials-grant-flow)

Для совместимости можно задать готовый пользовательский токен в `STREAMCUT_TWITCH_CLIP_TOKEN_<broadcaster_id>`. При таком варианте сервис использует этот токен. Для токена редактора укажите `STREAMCUT_TWITCH_CLIP_EDITOR_ID_<broadcaster_id>`. После истечения пользовательского токена его нужно заменить или перейти на токен приложения. Подтверждение редактора или владельца действует в пределах выданных полномочий. [Twitch Access Token Scopes](https://dev.twitch.tv/docs/authentication/scopes/)

Для автоматической предзагрузки роликов Twitch в YouTube укажите в `STREAMCUT_YOUTUBE_AUTO_TWITCH_BROADCASTERS` числовые ID авторов, от которых получено разрешение на публикацию. Разделяйте ID запятыми. При пустом списке готовые ролики остаются на проверке. Это отдельная настройка от доступа к скачиванию. После изменения переменной перезапустите сервис.

Старый поиск по авторам доступен при `STREAMCUT_DISCOVERY_MODE=regional`.

## Как меняется список

- В каждом направлении отображается до десяти авторов с подтверждённым сигналом. Для записей учитывается скорость набора просмотров за последние три дня, для эфира — число одновременных зрителей в момент проверки. Позиции рассчитываются отдельно по площадке и типу материала. Позиции автора в разных группах складываются. Если подтверждённых авторов меньше десяти, список будет короче.
- YouTube ищет по теме и по группам псевдонимов. Перезалив попадает в кандидаты, если в основном заголовке или названии канала однозначно найден известный автор. Язык незнакомого автора ожидается в метаданных видео. `regionCode` задаёт доступность видео для рынка. Это не статистика страны зрителей или гражданство авторов. [YouTube Search](https://developers.google.com/youtube/data/reference/rest/v3/search/list), [YouTube Videos](https://developers.google.com/youtube/data/reference/rest/v3/videos/list).
- Twitch ищет в категории GTA 6 по языку и проверяет эфиры и записи стартовых авторов. Эфир и архив связываются по `stream_id`, в том числе после перезапуска. Активные эфиры отображают состояние на момент последнего запроса. [Twitch Streams](https://dev.twitch.tv/docs/api/reference/streams), [Twitch Videos](https://dev.twitch.tv/docs/api/reference/videos).
- Поиск YouTube делает до пяти запросов `search.list` на регион за цикл, до 75 за 24 часа при пяти циклах. Дополнительные сведения о видео берутся пакетно. Общее потребление Google Cloud зависит от остальных клиентов проекта. [Документация квот](https://developers.google.com/youtube/data/determine_quota_cost).

## Как передать разрешённую запись на монтаж

Поиск сохраняет метаданные и ссылку. Для автоматически связанного монтажа кладите доступные для использования файлы в `inbox/RU`, `inbox/EN` или `inbox/ESP` с именами:

- `youtube-<video_id>.mp4` для видео YouTube;
- `twitch-vod-<video_id>.mp4` для записи Twitch;
- `twitch-stream-<stream_id>.mp4` для собственной записи эфира или записи, предоставленной с разрешением.

Передавайте файл с временным расширением и переименуйте после завершения копирования. Сервис может получить файл раньше метаданных и дождётся совпадения ID и языка. Загрузить файл через браузер и задать настройки реакции можно через «Настроить монтаж» у источника. Для публикации действует отдельная проверка языка, режима отправки, OAuth, канала и маршрута.
