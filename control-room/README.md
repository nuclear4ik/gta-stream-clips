# Streamcut

Личная панель из четырёх разделов: «Очередь», «Источники», «Аккаунты», «Подключения». На закрытом сайте Sites доступен предпросмотр. Рабочая панель и данные обслуживаются Python-сервисом.

## Запуск

Нужны Python 3.11+, FFmpeg и ffprobe в PATH. Из этой папки:

```sh
python3 studio.py --data .streamcut-data
```

Откройте [рабочую панель](http://127.0.0.1:8765/). Повторно используйте тот же путь к данным, чтобы сохранить аккаунты и очередь. Без `--data` программа использует `~/.streamcut`. Сервис слушает только loopback. Для запуска на сервере используйте [настройку Kubernetes](deploy/README.md) или SSH-туннель к отдельному сервисному пользователю. Хранилище, API и OAuth callback нельзя выставлять в публичный интернет.

`npm run dev -- --data .streamcut-data` запускает тот же сервис. `npm run preview` показывает статический интерфейс с примерами.

## Очередь и источники

- Twitch проверяется раз в пять часов. Сервис отдельно для RU, EN и ESP выбирает до десяти каналов категории Grand Theft Auto VI по текущим зрителям и проверяет их свежие публичные архивы. Для поиска нужны `TWITCH_CLIENT_ID` и `TWITCH_CLIENT_SECRET`. [Получение исходных файлов](CREATORS.md)
- Сервис связывает файл `twitch-vod-<id>.mp4` во входящей папке нужного языка с найденным архивом. Также доступны браузерная загрузка до 2 ГиБ и ручной ввод ссылки.
- В локальном запасе до десяти готовых MP4 на язык с описанием и хештегами. RU-ролик освобождает место после подтверждения даты в YouTube. Окна по Москве идут с 09:00 до 18:00, до десяти слотов за календарные сутки.
- При свободном слоте воркер заранее загружает вертикальный MP4 с будущим временем `publishAt`. Список «Запланировано в YouTube» показывает подтверждённые даты. Когда календарь заполнен или API отложил запрос, задание ждёт локально. `STREAMCUT_YOUTUBE_SCHEDULE_LIMIT` задаёт собственный размер календаря, по умолчанию десять. Квоты YouTube действуют отдельно.
- Пауза останавливает новые передачи. Переданные в календарь ролики выходят по расписанию YouTube. Перенос подтверждённого задания обновляет дату непосредственно на площадке. При неопределённом результате загрузки источник остаётся для проверки в Studio, повторная передача автоматически не запускается.

## Монтаж реакции

Для фонового монтажа установите `faster-whisper==1.2.1` и `opencv-python-headless>=4.8,<5` в окружение сервиса. Запустите Ollama, задайте `STREAMCUT_OLLAMA_MODEL` и `STREAMCUT_AUTOCUT=1`. По умолчанию автоматический режим работает для RU. `STREAMCUT_AUTOCUT_LANGS=RU,EN,ESP` расширяет языки, а `STREAMCUT_AUTOCUT_WHISPER_MODEL` меняет модель Whisper. Реплики распознаются из оригинальной дорожки, Ollama предлагает эпизоды, редактор вырезает 25–50 секунд по границам реплик. Длинные записи анализируются выборочными окнами.

OpenCV ищет устойчивое положение веб-камеры. При сложной сцене можно задать повторно используемое правило `STREAMCUT_AUTOCUT_LAYOUTS` с JSON-массивом, полем `facecam` и шаблоном `filename` или `title`. Источник остаётся в ожидании, когда камера определяется неоднозначно. Ручная настройка доступна из карточки.

1. На вкладке «Источники» добавьте видео или откройте «Настроить монтаж» у найденной записи.
2. Укажите область камеры, при необходимости область геймплея и заголовок из 3–5 слов. Каждая область задаётся как `x,y,ширина,высота` в пикселях или процентах исходного кадра от левого верхнего угла. Если область геймплея пуста, редактор возьмёт крупнейшую часть кадра рядом с камерой.
3. Добавьте расшифровку с таймкодами в формате UTF-8 SRT (до 512 КиБ). Можно вставить текст или выбрать файл.
4. Выберите способ отбора и сохраните источник. Готовые клипы появятся на его карточке.

**Автоматически по видео** использует пики звука и движения. С SRT редактор берёт из него субтитры. При отсутствии SRT для реакции нужен faster-whisper.

**Точные интервалы** принимает до шести строк, например `00:12:15 — 00:12:43 — Погоня через весь город`. Начало и конец задаются по исходнику. Для этого режима требуется SRT.

**Нейросеть по SRT** выбирает до трёх непересекающихся эпизодов и пишет короткие заголовки на языке источника. Запустите Ollama на том же хосте и задайте сервису `STREAMCUT_OLLAMA_MODEL` с именем установленной локальной модели. Для проверки RU, EN и ESP использовали `qwen3:4b-instruct`. По умолчанию используется `127.0.0.1:11434`, порт можно задать через `STREAMCUT_OLLAMA_PORT`. В контейнере Ollama должна быть доступна в той же сетевой среде. В модель передаётся текст SRT с таймкодами. Если расшифровка превышает лимит модели, разбейте её на части с исходными таймкодами или задайте интервалы вручную.

Сверху будет веб-камера, снизу — геймплей. На стыке отображается заголовок, субтитры выровнены по центру нижней зоны. В MP4 сохраняется исходный звук. По умолчанию отправка в соцсети выключена.

### Входящая папка

Для монтажа из входящей папки можно по-прежнему положить `stream.reaction.json` и `stream.srt` рядом с `stream.mp4`. Пример координат для конкретной сцены OBS.

```json
{
  "facecam": "74%,70%,25%,29%",
  "gameplay": "0%,0%,74%,100%",
  "headline": "Реакция на первый трейлер"
}
```

Запись YouTube или Twitch без профиля ждёт границ камеры. Настройте их в карточке или положите JSON рядом с файлом. Чтобы требовать профиль реакции и для записей без ссылки, задайте `STREAMCUT_REACTION_ONLY=1`. Для реакции требуется звуковая дорожка и реплики внутри выбранного фрагмента.

## Аккаунты

Добавляйте несколько своих каналов в раздел YouTube, TikTok или Instagram. Внутри каждой площадки каналы сгруппированы по аудитории. Предложенные названия можно изменить при добавлении.

**YouTube.** Включите YouTube Data API v3 в Google Cloud. Для статистики также нужен YouTube Analytics API. Задайте `STREAMCUT_GOOGLE_CLIENT_ID` и `STREAMCUT_GOOGLE_CLIENT_SECRET` из OAuth-клиента. Для Web application зарегистрируйте точный callback панели `http://127.0.0.1:8765/oauth/youtube`, заменив порт, если запускали с `--port`. Клиент Desktop app использует loopback. Если проект в External / Testing, добавьте аккаунт владельца канала в Audience → Test users. [Настройка Google OAuth](https://developers.google.com/workspace/guides/configure-oauth-consent#configure_oauth_consent)

Добавьте RU-аккаунт с ID канала `UC…`, нажмите «Подключить Google» и выберите этот канал. Для переноса даты используется scope `youtube.force-ssl`. Старую авторизацию для переноса может потребоваться обновить.

`STREAMCUT_YOUTUBE_UPLOAD=1` включает передачу роликов с будущим временем публикации. В карточке канала включите автопланирование, чтобы отправлять новые ролики с проверенным языком. Для пробного подключения достаточно загрузить ролик приватно без `publishAt`. Планирование не запускается при выключенном флаге.

По умолчанию передаётся стандартная лицензия YouTube (`youtube`) и `selfDeclaredMadeForKids=false`. Чтобы выбрать Creative Commons для собственного материала, задайте `STREAMCUT_YOUTUBE_LICENSE=creativeCommon`. Возрастное ограничение 18+ и проверки использования контента просматриваются в YouTube Studio. [Поля загрузки YouTube](https://developers.google.com/youtube/data/reference/rest/v3/videos/insert) · [Возрастное ограничение](https://support.google.com/youtube/answer/2950063)

**Instagram.** Для статистики профессионального аккаунта можно задать `STREAMCUT_INSTAGRAM_METRICS_<id>` с действующим токеном Instagram Login и разрешениями `instagram_business_basic` и `instagram_business_manage_insights`. ID карточки показывается при настройке сохранённого аккаунта. Суточные метрики выводятся, если Meta вернула значения. Прямой экспорт MP4 для ручной публикации доступен из очереди.

**TikTok.** Для общего числа подписчиков можно задать `STREAMCUT_TIKTOK_METRICS_<id>` с действующим Display API токеном и разрешениями `user.info.profile`, `user.info.stats`. Суточных метрик этот API не возвращает. Автоматическая публикация TikTok в личный инструмент не подключена. Токены TikTok и Instagram передаются в окружение, их продление выполняется вне панели. Пропущенные метрики обозначаются тире.

Регистрация и материалы по официальным платформам — в [ACCOUNT_SETUP.md](../ACCOUNT_SETUP.md).

## Подключения и восстановление

Вкладка показывает ожидаемую и фактическую страну выхода, доступность API по HTTPS и время последней проверки. Прямой «Сервер» использует обычную сеть хоста. Профили RU/US/ES используют настроенный владельцем доверенный маршрут. Настройки окружения и способ запуска указаны в [инструкции Kubernetes](deploy/README.md).

Перед YouTube OAuth и непосредственно перед отправкой сервис проверяет регион и API выбранного маршрута. Проверка доставки дополнительно сверяет выданный OAuth доступ с ID канала. При сбое сеть проверяется снова фоновым заданием примерно раз в минуту. Отправка в этом профиле ждёт восстановления без перехода на другой маршрут. После успешной проверки просроченные задания получают новые слоты. Уже начатую загрузку остановка маршрута не откатывает. При неопределённом результате требуется ручная сверка.

Kubernetes перезапускает контейнер сервиса и сохраняет состояние на томе. Доступность внешнего шлюза зависит от его инфраструктуры. Страна выхода — параметр сети. Географию зрителей оценивайте по фактической аналитике площадки.
