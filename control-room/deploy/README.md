# Личный запуск в Kubernetes

Streamcut слушает только 127.0.0.1 внутри Pod. Панель открывается через авторизованный `kubectl port-forward`. У манифеста нет Ingress, публичного сервиса или токена ServiceAccount в контейнере.

Перед запуском нужен выбранный Kubernetes-контекст, StorageClass с поддержкой `fsGroup` и возможность доставить контейнер в кластер. Для пилота выделены 20 ГиБ под базу, исходники и готовые видео. При большом объёме выберите подходящее хранилище и политику хранения заранее. Папка состояния внутри тома закрыта для других пользователей контейнера. Учитывайте, что администратор кластера с доступом к тому может прочитать его содержимое.

## Образ и запуск

Выполняйте сборку из корня `gta-stream-clips`.

```sh
docker build -f control-room/deploy/Dockerfile -t streamcut:local .
```

Для автомонтажа соберите с `--build-arg WITH_WHISPER=1` и задайте `STREAMCUT_AUTOCUT=1`. В той же сетевой среде запустите локальную Ollama и задайте `STREAMCUT_OLLAMA_MODEL`. Модель распознавания загружается при первой обработке, а её кэш сохраняется на томе. Проверьте доступ к файлам модели и запас памяти на своих записях.

Загрузите образ в локальный кластер или отправьте в ваш registry. Для удалённого кластера укажите в `streamcut.yaml` образ с именем registry и версионным тегом. Подставьте отдельное пространство имён, доступное только вам и администраторам вашей инфраструктуры.

```sh
kubectl config current-context
kubectl -n streamcut apply -k control-room/deploy
kubectl -n streamcut rollout status deployment/streamcut
kubectl -n streamcut port-forward --address=127.0.0.1 deployment/streamcut 8765:8765
```

Откройте [локальную панель](http://127.0.0.1:8765/). Оставьте порт 8765 на обеих сторонах. URL OAuth и проверка Host ожидают этот порт. После замены Pod запустите команду port-forward снова.

`streamcut-secrets` — необязательный Secret того же пространства имён. В нём можно задать OAuth, доступ к API поиска и адреса установленных вами доверенных маршрутов `STREAMCUT_PROXY_RU`, `STREAMCUT_PROXY_US`, `STREAMCUT_PROXY_ES`. Значения не должны попадать в исходники, образ или журнал. После обновления окружения Secret перезапустите Deployment. В Kubernetes Secret кодируется, но шифрование при хранении зависит от настройки кластера.

### Доверенный шлюз для YouTube

Если у вас есть собственный HTTP CONNECT в приватной сети, укажите его адрес в `STREAMCUT_UPLOAD_GATEWAY`, например `http://gateway.internal:8080`. Выберите «Доверенный шлюз» в карточке аккаунта и проверьте YouTube на странице «Подключения». Диагностика проверяет HTTPS через шлюз, страна выхода в этой проверке не используется.

При `STREAMCUT_YOUTUBE_REQUIRE_GATEWAY=1` предзагрузка и перенос в YouTube выполняются только через этот шлюз. При сбое до передачи файла задания ждут восстановления. Ролики, которые YouTube уже принял в своё расписание, выходят по своему расписанию на стороне YouTube.

## Что восстанавливается

- Kubernetes проверяет сам сервис через `/healthz` и перезапускает контейнер при его отказе. Очередь SQLite и файлы остаются на постоянном томе. Используется один экземпляр, чтобы два процесса не отправляли задания из одной очереди.
- Streamcut проверяет HTTPS API через выбранный маршрут. Для маршрутов с ожидаемой страной проверяется также страна выхода. Для загрузки отдельно проверяются OAuth и канал.
- При недоступности нужного маршрута очередь этого маршрута ждёт его восстановления. Подача новых заданий и диагностика остаются доступны, остальные здоровые маршруты могут работать. Не подтверждённая площадкой отправка требует сверки с YouTube Studio.
- Kubernetes перезапускает только управляемые им контейнеры. Внешний шлюз или туннель обслуживается отдельно. Нужна связь с доверенным шлюзом из сети Pod. Диагностика региона не задаёт географию показа ролика.

Проверка YAML без кластера:

```sh
kubectl kustomize control-room/deploy
```

Документация Kubernetes: [проверки контейнера](https://kubernetes.io/docs/concepts/workloads/pods/probes/), [контекст безопасности](https://kubernetes.io/docs/tasks/configure-pod-container/security-context/), [доступ через port-forward](https://kubernetes.io/docs/reference/kubectl/generated/kubectl_port-forward/).
